# 测试

> 状态：草案 v0.1 ｜ 更新：2026-11-01

## 1. 测试策略

| 层级 | 范围 | 手段 | 频率 |
|---|---|---|---|
| 单元测试 | 纯函数：日出日落、配置解析、调度计算、状态转移（热键解析自 v0.2） | doctest + ctest | 每次提交 |
| 集成验证 | 注册表读写、广播、托盘（热键自 v0.2） | 虚拟机手工执行 | 每个版本 |
| 手工验收 | 交互、异常、无障碍、多环境 | 测试矩阵 | 发布前 |

原则：能在单元测试里覆盖的逻辑，不放到手工测试里；依赖 Windows 环境的部分接受手工验证，但必须有清单。

## 2. 单元测试

### 覆盖范围

| 模块 | 测试点 |
|---|---|
| `solar` | 赤道 / 中纬度 / 极昼 / 极夜；东西半球；跨日边界 |
| `config` | 默认值、缺失键、非法值、损坏文件、UTF-8 BOM、便携模式 |
| `hotkey`（v0.2） | `Ctrl+Alt+D`、`Win+Shift+F5`、非法组合、空字符串 |
| `scheduler` | 同日两点、跨天两点、日出日落、时间相同、未配置 |
| `app` 状态机 | 模式转移表逐条验证；覆盖与恢复 |

### 示例

示例取自 `hotkey` 模块（v0.2）。

```cpp
#define DOCTEST_CONFIG_IMPLEMENT_WITH_MAIN
#include "doctest.h"
#include "hotkey.h"

TEST_CASE("parse ctrl+alt+d") {
    auto spec = parse_hotkey(L"Ctrl+Alt+D");
    REQUIRE(spec.has_value());
    CHECK(spec->modifiers == (MOD_CONTROL | MOD_ALT));
    CHECK(spec->vk == 'D');
}

TEST_CASE("reject incomplete hotkey") {
    CHECK_FALSE(parse_hotkey(L"Shift+").has_value());
    CHECK_FALSE(parse_hotkey(L"").has_value());
}
```

测试目标编译时链接 `src/` 下的纯逻辑源文件，不链接 `main.cpp`、`tray.cpp`、`menu.cpp` 等依赖窗口的模块。

## 4. CI 门禁

| 检查 | 失败即阻断 |
|---|---|
| 编译警告 | `/W4 /WX` 零警告 |
| 单元测试 | 全部通过 |
| 依赖 | `dumpbin /dependents` 仅含系统 DLL |
| 格式 | clang-format 无 diff |
| 静态分析 | clang-tidy 无 error 级问题 |

体积不设门禁：CI 记录每次构建的 exe 体积，作为版本间对比基线；明显膨胀在评审中说明，不阻断发布。

## 5. 缺陷分级

| 级别 | 定义 | 处理 |
|---|---|---|
| P0 | 崩溃、无法切换、破坏系统设置 | 立即修复，阻断发布 |
| P1 | 功能不可用但有绕过方式 | 本版本修复 |
| P2 | 体验问题、偶发异常 | 排期修复 |
| P3 | 文案、视觉细节 | 可延后 |
