# ADR-0001：采用 C++23 + 原生 Win32 技术栈

> 状态：已接受 ｜ 日期：2026-11-01

## 背景

TinyTheme 需要在 Windows 上常驻托盘、注册全局热键、读写当前用户注册表并广播系统消息。产品定位是"轻量、免安装、低存在感"，因此发布物必须是单个可执行文件，且不依赖额外运行时。

## 决策

- 语言：C++23。
- UI：直接调用 Win32 API（`Shell_NotifyIconW`、`RegisterHotKey`、`CreatePopupMenu`、隐藏窗口消息循环）。
- 编译器：MSVC v143。
- 构建：CMake + Ninja。
- 运行库：静态链接（`/MT`）。

## 理由

1. 功能面完全落在 Win32 API 上，不需要任何 UI 框架的抽象层。
2. 单个 exe 即可交付，无 DLL、无运行时安装步骤。
3. 编译产物小、冷启动快，符合"低存在感"的产品目标。
4. MSVC 与 Windows SDK 对目标 API 的支持最完整，调试符号与系统调用栈一致。

## 后果

正面：

- 发布物是一个几百 KB 的 exe，用户解压即用。
- 没有第三方依赖，供应链简单，安全审计成本低。
- 可以直接控制消息循环与资源生命周期，行为可预测。

负面 / 约束：

- Win32 样板代码较多，需要自建轻量 RAII 与工具函数。
- 内存安全依赖开发者自律，评审时需重点关注缓冲区与句柄。
- UI 能力有限，复杂界面（如设置窗口）需要手写对话框资源。

## 合规检查

- 不引入 UI 框架、不使用 COM（v0.3 评估壁纸接口时另行决策）。
- 所有系统调用失败路径必须有日志。
- 新增源文件默认纳入 `/W4 /WX`。
