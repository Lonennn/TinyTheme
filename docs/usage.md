# 使用指南

> 状态：v0.1 已实现 ｜ 更新：2026-11-02

面向使用者的完整说明：日常操作、便携模式、配置文件、日志、卸载与已知限制。
README 只保留最短上手路径，细节都在这里。

行为规范（菜单结构、键位、状态机）见 [交互设计](product/04-interaction-design.md)；
键名与默认值的实现依据见 [配置与运行时](engineering/05-config-and-runtime.md)。

## 1. 日常操作

| 操作 | 结果 |
|---|---|
| 左键单击托盘图标 | 立即切换浅色 / 深色 |
| 右键单击托盘图标 | 打开菜单：状态摘要、浅色 / 深色单选、开机启动、退出 |
| 双击托盘图标 | 打开配置文件 `config.ini` |
| 右键 → 退出 | 结束进程（不改变当前主题） |

图标即状态：**太阳 = 当前浅色，月亮 = 当前深色**，悬停提示显示"当前：深色（左键切换）"。
切换后系统会向所有应用广播主题变更；个别旧 Win32 / UWP 应用不响应，需要重启该应用才生效。

首次运行会写入默认配置并注册开机启动（可在菜单里取消勾选）。

## 2. 便携模式

在 exe 同目录放一个空的 `portable.ini`，配置就改写到 exe 同目录的 `config.ini`。

- 便携判定只看 `portable.ini` **是否存在**，不读内容。
- 便携模式下**不会**自动注册开机启动，需要手动勾选。
- 目录不可写时回退到 `%APPDATA%`，并在日志里记一条 `warn`。

## 3. 配置文件

| 模式 | 路径 |
|---|---|
| 标准 | `%APPDATA%\TinyTheme\config.ini` |
| 便携 | exe 同目录 `config.ini` |

文件为 UTF-8 with BOM：

```ini
[general]
mode=dark            ; light / dark，当前主题的镜像，启动以注册表为准
include_system_theme=1
autostart=1
show_toast=1
language=auto

[meta]
first_run=0
```

- 改完需重启程序生效（双击图标也能直接打开，省得找路径）。
- 非法值逐键回退默认，不会让整个配置失效。
- 文件损坏会被重命名为 `config.ini.bak.<时间戳>`，程序重建默认值。
- `language` 在 v0.1 只识别简体中文，多语言自 v0.3 起。

## 4. 日志

`%LOCALAPPDATA%\TinyTheme\logs\app.log`

- 单文件 256 KB 轮转，保留 3 份历史。
- 每条立即 flush，崩溃时不会丢最后几行。
- `%LOCALAPPDATA%` 不可写时退回 exe 同目录的 `logs\`；仍失败则本次运行禁用日志。
- 只记录启动退出、配置加载、主题写入结果与失败原因，不记录窗口标题、用户名等隐私信息。

反馈问题请附上日志末尾几行；日志里的时间戳与错误码是最快的定位线索。

## 5. 升级与卸载

- **升级**：右键 → 退出，用新 exe 覆盖旧文件即可；配置与开机自启设置会保留。
- **卸载**：右键 → 退出 → 菜单里先取消"开机启动"，再删除 exe。
  直接删 exe 会残留 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `TinyTheme` 值。
- 想彻底清干净，再删掉 `%APPDATA%\TinyTheme`、`%LOCALAPPDATA%\TinyTheme` 两个目录。

## 6. 已知限制

v0.1 是单点功能的 MVP，以下都是已知缺口，不加遮掩：

| 限制 | 现状 | 计划 |
|---|---|---|
| 没有自动切换 | 只有手动浅 / 深两态 | v0.2 定时与日出日落 |
| 没有全局热键 | 只能点托盘 | v0.2 补 `Ctrl+Alt+D` |
| 无高对比度保护 | 高对比度用户不应依赖 v0.1 | v0.2 补齐 |
| 外部改主题后图标不刷新 | 重启或下次切换才恢复 | v0.2 补齐 |
| 菜单无"关于 / 打开配置文件" | 双击图标代替 | v0.2 |
| 仅简体中文 | `language` 键预留 | v0.3 多语言 |
| 部分旧应用不响应广播 | 本工具不重启 `explorer.exe` | 不计划做 |
| 构建未签名 | 首次运行可能被 SmartScreen 拦截 | 发布前签名 |

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击后提示"Windows 已保护你的电脑" | 未签名触发 SmartScreen：选"更多信息 → 仍要运行" |
| 托盘图标不见了 | Windows 会把新图标收进"隐藏的图标"里：拖到任务栏上固定 |
| 提示无法创建托盘图标，日志是 `NIM_ADD` 错误 5 | 在低权限目录或受限沙箱里运行：把 exe 复制到普通目录 |
| 切换后某些应用颜色没变 | 该应用不响应 `WM_SETTINGCHANGE`：重启该应用 |
| 开机没自动启动 | 检查菜单里"开机启动"是否勾选；便携模式默认不注册 |
| 两个实例同时运行 | 不可能：第二个实例只会唤起已有菜单，然后自行退出 |
