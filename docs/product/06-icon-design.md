# 托盘图标设计

> 状态：草案 v0.1 ｜ 更新：2026-11-01

托盘图标是产品唯一的常驻视觉元素：用户不打开任何窗口，只靠任务栏上这一个 16 px 的图形判断当前主题。本文约束它的形状、尺寸、颜色与状态映射；生成与打包流程见 [图标生成](../engineering/10-icon-pipeline.md)。

## 1. 设计目标

| 目标 | 判定方式 |
|---|---|
| 16 px 下可辨认 | 不放大也能一眼分清太阳与月亮 |
| 两种任务栏都可读 | 浅色任务栏用深色描边，深色任务栏用浅色描边 |
| 低存在感 | 单色线稿，与系统图标同一视觉重量 |
| 状态可读 | 太阳 = 当前浅色，月亮 = 当前深色 |

## 2. 设计原则

1. **先画 16 px**：16 px 成立才做 20 / 24 / 32，不反过来缩。
2. **单色线稿**：不用彩色、渐变、投影，不在任务栏里抢注意力。
3. **只表达主题**：图标反映"当前是浅色还是深色"，不表达模式（浅色 / 深色由菜单表达；自动模式 v0.2）。
4. **轮廓优先**：靠外形区分，不靠内部细节；16 px 下细节会被吃掉。
5. **两图形等重**：太阳与月亮并排看，不能一个明显更粗或更满。

## 3. 图形

| 项 | 浅色主题（浅色任务栏） | 深色主题（深色任务栏） |
|---|---|---|
| 图形 | 太阳 | 月亮 |
| 资源 | `IDI_LIGHT` | `IDI_DARK` |
| 描边 | 深色 | 浅色 |

### 3.1 画布

- 母版画布 32 × 32，1 用户单位 = 1 px，透明背景。
- 安全区 28 × 28（距边缘 2 px）；含圆头线帽在内，任何笔画不出安全区。
- 母版线宽 2，其他档位按 §4 取值。

### 3.2 太阳

- 内圆圆心 (16, 16)、半径 6，线宽 2。
- 8 道光芒，每 45° 一道，自半径 10 画到 12，线宽 2，圆头线帽。
- 光芒与内圆的净空 ≥ 2（母版单位，即 16 px 下的 1 px），避免缩到 16 px 时粘成一团。
- 正圆，不做透视或倾斜。

### 3.3 月亮

- 外圆圆心 (16, 16)、半径 10，线宽 2。
- 从右上挖去圆心 (18.5, 13.5)、半径 9 的圆，月牙最厚处约 4.5。
- 缺口朝右上：与太阳的放射方向区分开，16 px 下不会误认成"带缺口的光斑"。
- 月牙过薄在 16 px 下会断线，过厚会读成满月；厚度以 §8 的目视结果定稿。

### 3.4 视觉重量

- 两图形各自在 28 × 28 安全区内居中，不共用外接框。
- 32 px 下并排对比，不允许一个明显更粗或更满；需要时调光芒长度或月牙厚度，不改整体尺寸。
- 与音量、网络、电池等系统图标并排时不显得更重——这是"低存在感"的验收点之一。

> §3.2 / §3.3 的坐标是首版起始值，首次渲染后按 §8 目视校准并回写本文。

## 4. 尺寸与线宽

| 尺寸 | 线宽 | 对应缩放 | 备注 |
|---|---|---|---|
| 16 | 1 | 100% | 整像素对齐，不允许断线 |
| 20 | 1 | 125% | 整像素对齐 |
| 24 | 1.5 | 150% | 允许抗锯齿，目视确认不糊 |
| 32 | 2 | 200% | 整像素对齐 |

线宽基准是尺寸的 1/16；为了清晰，16 / 20 取整到 1 px，24 取 1.5，32 取 2。

四档由同一份 32 单位母版按目标尺寸**矢量重新渲染**（不是把 32 px 位图缩小），线宽随尺寸等比落到上表的 1 / 1.25 / 1.5 / 2；16 与 32 落在整像素，20 / 24 允许抗锯齿。

四档都必须提供：Windows 的系统托盘在 100% / 125% / 150% / 200% 缩放下分别取 16 / 20 / 24 / 32 px，缺哪一档，系统就会取邻近尺寸缩放，图标会发虚。

## 5. 像素对齐

- 1 px 线宽时，线条中心线落在 `x.5` 坐标上，正好覆盖一整列像素。
- 圆与斜线不可避免产生抗锯齿；16 px 下要求灰边连续，不允许断成虚线。
- **四档分别渲染、分别检查**，不得用 32 px 的位图缩小到 16 px 来验收。

## 6. 颜色

| 用途 | 值 |
|---|---|
| 浅色主题描边 | `#000000` |
| 深色主题描边 | `#FFFFFF` |
| 背景 | 透明（alpha = 0） |

- 不使用半透明描边：在深浅两种背景上都会变成灰边。
- 不描内边、不加外发光。
- 颜色不在运行时计算，两套图标各自带色。

## 7. 状态映射

| 系统主题 `SystemUsesLightTheme` | 资源 | 图形 |
|---|---|---|
| 1（浅色任务栏） | `IDI_LIGHT` | 太阳，深色描边 |
| 0（深色任务栏） | `IDI_DARK` | 月亮，浅色描边 |

规则：

- **只跟随系统主题**，不跟随应用主题。F-12（仅切换应用主题，v0.3）启用后，应用主题变化不影响图标。
- **不区分模式**：浅色、深色（v0.2 起含自动及临时覆盖），图标都只表示当前实际主题。
- **混合状态**（应用深色 + 系统浅色）按系统主题显示太阳；菜单里的状态摘要仍显示"深色（应用）/ 浅色（系统）"。
- **v0.1**：启动时按系统主题选定一次，运行中系统主题变化后不刷新。
- **v0.2**：随 F-11 补齐 `WM_SETTINGCHANGE` 之后的刷新。
- **高对比度**：沿用当前图标，不做专门变体；对比度是否足够由 F-10（v0.2）验证。
- **资源缺失**：回退到系统默认图标 `IDI_APPLICATION`，不显示空白。

## 8. 可辨识度验收

- [ ] 16 px：太阳 8 道光芒彼此不粘连；月亮缺口清晰、月牙不断线。
- [ ] 与音量、网络、电池等系统图标并排，不显得更粗或更重。
- [ ] 浅色任务栏、深色任务栏各截一张图。
- [ ] 100% / 150% / 200% 三种缩放下分别检查（对应 16 / 24 / 32 档）。
- [ ] 判断依据是实际像素效果，不是放大预览。

## 9. 资产与命名

| 文件 | 内容 | 入库 |
|---|---|---|
| `res/icon-light.svg` | 太阳源文件，32 × 32 画布 | 是 |
| `res/icon-dark.svg` | 月亮源文件 | 是 |
| `res/icon-light.ico` | 16 / 20 / 24 / 32 四档打包 | 是 |
| `res/icon-dark.ico` | 同上 | 是 |
| `res/build/*.png` | 光栅化中间产物 | 否 |

- 文件名小写连字符，与资源 ID 的对应关系见 §7。
- ICO 内条目按 16 → 32 升序排列，兼容只取第一条的旧接口。

## 10. 明确不做

- 彩色、渐变、投影、外发光。
- 动画图标（旋转、呼吸、闪烁）。
- 第三种"自动模式"图标或角标。
- 用字体图标（Segoe Fluent Icons）代替位图资源。
- 运行时把 SVG 渲染成图标，见 [图标生成](../engineering/10-icon-pipeline.md)。
