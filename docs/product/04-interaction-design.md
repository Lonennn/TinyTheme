# 交互设计

> 状态：草案 v0.1 ｜ 更新：2026-11-01

## 1. 设计原则

1. **一次点击**：最高频的操作必须一次点击完成，不经过菜单、不打开窗口。
2. **零学习成本**：图标本身表达当前状态，左键切换是 Windows 托盘的通用心智。
3. **不打扰**：默认不弹通知、不抢焦点、不闪任务栏。
4. **可预期**：同样的操作永远得到同样的结果；自动模式的行为在菜单里可见。
5. **失败可见但不阻塞**：出错时提示一次，然后继续可用。

## 2. 托盘图标

| 项 | 规范 |
|---|---|
| 形态 | 太阳（浅色）/ 月亮（深色），线性风格，单色 |
| 尺寸 | 16 / 20 / 24 / 32 四档，按 DPI 选择 |
| 颜色 | 跟随系统主题：浅色任务栏用深色描边，深色任务栏用浅色描边 |
| 悬停提示 | `TinyTheme — 当前：深色（左键切换）` |
| 变化时机 | 启动时按系统主题选定（v0.1）；系统主题变化后刷新（v0.2） |

图标不使用彩色，避免在任务栏中过于显眼；这是"低存在感"的一部分。

图形参数、像素对齐、色值与状态映射的完整规范见 [托盘图标设计](06-icon-design.md)。

## 3. 鼠标与键盘行为

| 操作 | 行为 |
|---|---|
| 左键单击 | 切换主题，不弹菜单 |
| 右键单击 | 弹出菜单 |
| 双击 | 打开配置文件（`config.ini`） |
| 键盘聚焦图标后按空格 / 回车 | 等同左键 |
| 键盘聚焦图标后按 Shift+F10 | 弹出菜单 |
| 全局热键 `Ctrl+Alt+D`（v0.2） | 切换主题（P1，注册失败不影响托盘路径） |

托盘左键是 P0 保底路径，也是 v0.1 唯一的切换入口；全局热键为 P1，自 v0.2 起提供，注册失败时提示一次并继续以托盘方式工作。

## 4. 菜单结构

```
┌────────────────────────────────────┐
│ 当前：深色（应用 / 系统）            │  ← 禁用项，仅展示
├────────────────────────────────────┤
│ ● 浅色                              │
│ ○ 深色                              │
│ ○ 自动（07:30 / 19:00）             │
├────────────────────────────────────┤
│ ☑ 开机启动                          │
│   打开配置文件                       │
│   关于 TinyTheme                    │
├────────────────────────────────────┤
│   退出                              │
└────────────────────────────────────┘
```

规则：

- 第一项为状态摘要，永远禁用。应用主题与系统主题不一致时显示"深色（应用）/ 浅色（系统）"，即混合状态。
- 浅色 / 深色 / 自动三项为单选，选中项前有圆点。
- 自动项括号内展示当前生效的切换时刻；使用日出日落时显示"日出 / 日落"，未配置时显示"自动（未配置时间）"并置灰。
- 自动模式下发生临时覆盖时，自动项文案变为"自动（临时覆盖中）"。
- 高对比度开启时，浅色 / 深色 / 自动三项全部置灰，状态摘要显示"高对比度模式，已暂停"。
- "开机启动"为复选项，状态以注册表实际值为准。
- 菜单不出现快捷键提示之外的二级子菜单，保持一屏可见。

## 5. 通知规范

使用托盘气泡，不引入系统 Toast 框架。

| 场景 | 文案 | 频率 |
|---|---|---|
| 首次运行 | 左键单击切换主题，右键查看更多 | 仅一次 |
| 热键被占用（v0.2） | 快捷键被其他程序占用，请在配置文件中修改 | 每次启动最多一次 |
| 切换失败 | 切换失败，请查看日志 | 每次运行最多一次 |
| 高对比度 | 高对比度模式已开启，主题切换暂停 | 每次开启最多一次 |
| 图标被折叠 | 图标在"隐藏的图标"中，可拖到任务栏固定 | 仅一次 |

不在每次切换时弹提示——切换本身就是反馈。

## 6. 首次运行

1. 创建配置目录，写入默认配置（自动模式、`07:30` / `19:00`、开机启动开启）。
2. 注册开机启动。
3. 显示托盘图标。
4. 弹出一次引导气泡。
5. 不打开任何窗口，不弹出"欢迎"对话框。

## 7. 异常与降级

| 异常 | 表现 | 恢复方式 |
|---|---|---|
| 热键注册失败（v0.2） | 气泡提示，托盘左键仍可用 | 修改配置后重启 |
| 注册表写入失败 | 气泡提示，状态不改变 | 检查权限 / 安全软件拦截 |
| 图标资源缺失 | 使用系统默认图标 | 重新安装 |
| 配置文件损坏 | 备份后重建默认配置 | 自动 |
| 高对比度开启 | 全部切换入口置灰 | 关闭高对比度后自动恢复 |
| 第二个实例启动 | 弹出已有实例的菜单 | 自动 |

## 8. 无障碍

- 所有菜单项支持键盘导航，方向键 + 回车可完成全部操作。
- 托盘图标支持 `NIN_KEYSELECT`，键盘可聚焦。
- 悬停提示包含当前状态，屏幕阅读器可读取。
- 高对比度模式下不执行任何颜色写入，避免破坏用户已配置的对比度方案。
- 菜单文字不使用纯图标代替，保证可朗读。

## 10. 视觉细节

- 菜单使用系统原生菜单，跟随系统主题（深色模式下启用深色菜单）。
- 状态摘要使用次要文字颜色，与可点击项区分。
- 不使用自定义绘制的悬浮面板，避免引入额外的窗口管理与 DPI 适配成本。
- 托盘图标在切换后 100 ms 内完成更新，避免"主题变了图标没变"的错位感。
