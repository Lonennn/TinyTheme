# 用户与场景

> 状态：草案 v0.1 ｜ 更新：2026-11-01

## 1. 用户画像

### P-1 夜间开发者 · 阿哲

- 28 岁，后端工程师，每天 10 小时在 IDE 和终端里。
- 白天用浅色（办公室灯光强），晚上 8 点后切深色。
- 痛点：每晚手动切一次，早上再切回来，经常忘。
- 期望：到点自动切；临时想切时一个快捷键搞定。

### P-2 光线敏感者 · 小林

- 32 岁，设计相关，对屏幕亮度敏感。
- 不固定时间，凭感觉切换，一天 3–5 次。
- 期望：最快路径，最好闭着眼都能按。

### P-3 演示者 · 老周

- 45 岁，售前，经常投屏演示。
- 演示前切浅色（投影仪偏暗），演示后切回深色。
- 期望：切换要快、要可靠，不能切一半。

## 2. 核心场景

### S-1 快捷键切换（v0.2）

- 触发：用户按下 `Ctrl+Alt+D`。
- 前置：TinyTheme 正在运行，未开启高对比度模式。
- 步骤：按键 → 读取应用主题 → 取反 → 写注册表 → 广播 → 刷新托盘图标。
- 期望：300 ms 内完成变色；托盘图标同步变化；无窗口弹出。
- 异常：热键被占用 → 首次启动时提示；写注册表失败 → 气泡提示"切换失败"。
- 版本：v0.1 不提供本场景，手动切换全部由 S-2 承担；v0.2 引入后与 S-2 并行。

### S-2 托盘点击切换

- 触发：左键单击托盘图标。
- 期望：与 S-1 一致，且不弹出菜单。
- 定位：P0 保底路径；v0.1 唯一的切换入口，v0.2 起同时是热键不可用时的降级入口。
- 异常：图标被折叠进"隐藏的图标" → 首次运行提示如何固定到任务栏。

### S-3 右键菜单选择模式

- 触发：右键单击托盘图标。
- 步骤：弹出菜单 → 选择"浅色 / 深色 / 自动"。
- 期望：菜单勾选状态与实际模式一致；选择后菜单关闭并立即生效。
- 异常：点击菜单外部 → 菜单关闭，不改变状态。

### S-4 自动切换

- 触发：到达配置的切换时间（固定时间或日出日落）。
- 期望：静默切换，默认不弹通知；全屏应用中照常切换，不抢焦点。
- 异常：电脑休眠错过切换点 → 唤醒后立即补偿执行一次，且只执行一次。

### S-5 自动模式下的临时手动切换

- 触发：自动模式下用户左键单击了托盘图标（v0.2 起也可按热键）。
- 期望：立即切换，进入"临时覆盖"；到下一个计划切换点自动恢复自动模式。
- 异常：10 分钟内连续手动切换，不重复提示。

### S-6 首次运行

- 触发：第一次启动 exe。
- 步骤：写入默认配置 → 注册开机启动（默认开启）→ 显示托盘图标 → 气泡提示"左键切换，右键更多"。
- 期望：不弹主窗口；用户 10 秒内能完成第一次切换。

## 3. 用户旅程

| 阶段 | 用户动作 | 系统反馈 | 情绪 |
|---|---|---|---|
| 发现 | 看到别人托盘里的太阳 / 月亮图标 | — | 好奇 |
| 获取 | 下载 zip，解压，双击 | 托盘出现图标 + 气泡提示 | 期待 |
| 首次使用 | 左键点一下 | 屏幕立刻变色 | 惊喜 |
| 日常 | 左键点一下托盘图标（v0.2 起可换成 `Ctrl+Alt+D`） | 无感切换 | 习惯 |
| 进阶 | 打开菜单设成自动 | 到点自动切 | 省心 |
| 卸载 | 右键 → 退出，删除 exe | 托盘消失，仅剩配置目录 | 干净 |

## 4. 反场景（不适合谁）

- 需要按应用分别设置主题的用户 → 应使用专门的主题管理工具。
- 需要企业统一策略的 IT 管理员 → 不在范围内。
- 期望"切换主题同时换壁纸 / 强调色"的用户 → v0.3 之前不满足。
- 使用高对比度辅助模式的用户 → 主题切换本身无效，工具会主动禁用并提示。
