# 功能规格

> 状态：草案 v0.1 ｜ 更新：2026-11-01

## 2. 详细规格

### F-01 托盘左键切换

- 入口：左键单击托盘图标（`NIN_SELECT`）。
- 行为：读取当前应用主题 → 取反 → 写入 → 广播 → 刷新图标与菜单。
- 这是 P0 保底路径，任何环境下都必须可用。
- 边界：
  - 读取失败时按"当前为浅色"处理。
  - 写入失败时不改变内部状态，气泡提示"切换失败，请查看日志"。
  - 切换过程中重复触发：忽略 200 ms 内的重复请求（防抖）。

### F-02 全局热键切换（v0.2）

- 版本：v0.1 不实现本功能，配置项 `hotkey` 自 v0.2 起生效。
- 默认 `Ctrl+Alt+D`，可在配置文件中修改；空字符串表示禁用。
- 行为与 F-01 一致：读取 → 取反 → 写入 → 广播 → 刷新。
- 优先级 P1：热键注册失败或与其他程序冲突时，记录日志并提示一次，托盘路径不受影响。
- 边界：
  - 不自动切换备用组合键，避免与用户预期不一致。
  - 修改热键后需重启程序生效。

### F-03 模式选择

- v0.1：**仅浅色 / 深色**；不提供自动模式，不做自动所需的任何计算。自动模式与调度从 v0.2 开始。
- 浅色：应用浅色；深色：应用深色。选择后立即生效。
- 选择浅/深并把当前主题记录到配置 `mode`，作为当前状态的持久化镜像；启动以注册表实际主题为准，不强制改写。
- 外部修改系统主题时，以注册表为准刷新菜单/配置，不自动改回。
- v0.2 的自动模式：按 F-04 / F-05 在计划切换点切换；选择"自动"时立即计算当前应有主题并应用。

### F-04 自动调度 · 固定时间

- 配置两个时刻：`light_at`（切浅色）、`dark_at`（切深色），格式 `HH:mm`。
- 两者相同或缺失时，自动模式退化为"不自动切换"，并在菜单中置灰提示。
- 跨天处理：`dark_at` 早于 `light_at` 时，视为跨天区间，逻辑仍然成立。

### F-05 自动调度 · 日出日落

- 用户填写纬度、经度，可选偏移分钟数。
- 本地计算当日日出 / 日落时刻，不联网。
- 纬度绝对值 > 66.5° 时可能出现极昼 / 极夜，此时回退到固定时间并提示一次。
- 未填写经纬度时，本功能不启用。

### F-06 开机自启

- 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值为 exe 完整路径（带引号）。
- 菜单中的勾选状态以注册表实际值为准，不以配置为准。
- 便携模式下不自动开启，需用户手动勾选。

### F-07 配置持久化

- 位置：`%APPDATA%\TinyTheme\config.ini`。
- 便携模式：exe 同目录存在 `portable.ini` 时，配置写到 exe 同目录。
- 写入时机：设置变更立即写；退出时再写一次兜底。
- 配置损坏时：备份为 `config.ini.bak`，重建默认配置，不阻塞启动。

### F-08 单实例

- 命名互斥体 `Local\TinyTheme.Instance`。
- 第二个实例启动时，向第一个实例的隐藏窗口发送 `WM_APP + 1`，弹出菜单后退出。
- 不弹"程序已在运行"的对话框。

### F-09 状态提示

- 使用托盘气泡（`NIF_INFO`），不引入 Toast 通知框架。
- 触发场景：首次运行引导、热键注册失败、切换失败、高对比度阻断。
- 相同提示 24 小时内最多一次。

### F-10 高对比度保护

- 启动时与每次收到 `WM_SETTINGCHANGE` 时检测 `SPI_GETHIGHCONTRAST`。
- 开启时：停止自动调度，禁用手动切换，菜单项置灰，首次检测到提示一次。
- 关闭后：恢复之前的模式与调度。

### F-11 托盘图标自适应

- 两套图标：浅色版（深色描边）、深色版（浅色描边），设计规范见 `06-icon-design.md`。
- 依据 `SystemUsesLightTheme` 选择；v0.1 只在启动时选定，v0.2 补齐收到广播后的刷新。
- 图标尺寸按 `GetSystemMetrics(SM_CXSMICON)` 选择最接近的 16 / 20 / 24 / 32 像素资源。

### F-12 仅切换应用主题

- 配置项 `switch_system_theme=0` 时，只写 `AppsUseLightTheme`，不动 `SystemUsesLightTheme`。
- 默认值为 `1`（两者一起切）。

### F-13 主题编排（v0.3）

- 切换时按预设执行附加动作：换壁纸、改强调色、改编辑器主题（通过外部命令）。
- 每个动作可单独开关，失败不影响主题切换本身。
- 不内置壁纸资源，只引用本地文件路径。

### F-14 多语言

- 资源字符串集中在 `.rc` 的 `STRINGTABLE`。
- 语言选择顺序：配置项 > 系统 UI 语言 > 英文兜底。

## 3. 状态机

> v0.1 只实现 `Light`、`Dark` 与 Toggle/SelectLight/SelectDark；`Auto`、Override、Suspended 与 Boundary 留 v0.2。

状态：`Light`、`Dark`、`Auto`；`Auto` 带子状态 `Override(Light|Dark)`。

| 当前状态 | 事件 | 目标状态 | 动作 |
|---|---|---|---|
| Light | Toggle | Dark | 应用深色 |
| Dark | Toggle | Light | 应用浅色 |
| Auto | Toggle | Auto + Override(取反) | 应用取反后的主题 |
| Auto + Override | Toggle | Auto + Override(取反) | 应用取反后的主题 |
| 任意 | SelectLight | Light | 应用浅色，清除 Override |
| 任意 | SelectDark | Dark | 应用深色，清除 Override |
| 任意 | SelectAuto | Auto | 立即计算并应用当前应有主题，重新调度 |
| Auto | Boundary | Auto | 应用计划目标，清除 Override |
| Light / Dark | Boundary | 不变 | 忽略 |
| 任意 | HighContrastOn | Suspended | 停止调度，禁用手动切换 |
| Suspended | HighContrastOff | 恢复原状态 | 重新调度 |

不变量：

- 内部状态与注册表实际值不一致时，以注册表为准并记录日志。
- 任何时刻最多只有一个计划切换定时器。

## 4. 验收标准

- **AC-01**：给定应用主题为浅色，当用户左键单击托盘图标，则 300 ms 内应用主题变为深色，托盘图标变为深色版。
- **AC-02（v0.2，P1，不阻断发布）**：给定 TinyTheme 正在运行，当用户按下 `Ctrl+Alt+D`，则主题切换且不弹出任何窗口；若热键注册失败，则托盘路径仍可完成切换。
- **AC-03**：给定当前模式为自动且已临时覆盖为深色，当打开右键菜单，则"自动"项显示"（临时覆盖中）"且处于选中态。
- **AC-04**：给定模式为自动、`dark_at=19:00`，当系统时间到达 19:00，则主题变为深色且不弹通知。
- **AC-05**：给定模式为自动、当前为浅色，当用户左键单击托盘图标，则变为深色并进入临时覆盖；到达下一个计划切换点时恢复自动模式。
- **AC-06**：给定模式为自动、休眠期间错过了 19:00，当系统唤醒，则立即应用深色，且不会连续重复应用。
- **AC-07**：给定已有一个实例在运行，当再次双击 exe，则弹出菜单且不出现第二个托盘图标。
- **AC-08**：给定用户把模式改为深色，当退出并重新启动，则模式仍为深色。
- **AC-09**：给定系统开启高对比度，当启动 TinyTheme，则菜单项置灰并提示一次，不执行任何主题写入。
- **AC-10**：给定用户勾选"开机启动"，当检查 `HKCU\...\Run`，则存在指向当前 exe 的字符串值；取消勾选后该值被删除。

## 5. 非功能需求

| 编号 | 需求 | 目标 |
|---|---|---|
| NFR-01 | 发布物体积 | 单 exe 保持轻量（几百 KB 量级），不设硬性上限，以实测记录为准 |
| NFR-02 | 常驻内存 | 工作集 < 10 MB |
| NFR-03 | 冷启动 | < 100 ms 出现托盘图标 |
| NFR-04 | 切换耗时 | 点击到变色 < 300 ms |
| NFR-05 | 空闲 CPU | 0%（事件驱动，无轮询） |
| NFR-06 | 权限 | 普通用户，不弹 UAC |
| NFR-07 | 网络 | 不发起任何网络请求 |
| NFR-08 | 稳定性 | v0.1 连续运行 3 天无崩溃、无句柄泄漏；7 天为目标 |
| NFR-09 | 可访问性 | 全键盘可操作，支持高对比度提示 |
| NFR-10 | 卸载残留 | 仅 `%APPDATA%\TinyTheme` 与 `%LOCALAPPDATA%\TinyTheme`；若开启自启，删除 exe 前应先取消，否则 Run 值会残留 |
